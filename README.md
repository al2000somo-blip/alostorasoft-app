# Alostorasoft App

مشروع ويب بسيط تم إعداده كقاعدة أولية للتطوير. يحتوي المشروع على خادم Node.js بسيط وخدمة ملفات ثابتة لواجهة المستخدم.

## المتطلبات

- Node.js 18+
- npm

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm start
```

افتح المتصفح على:

```text
http://localhost:3000
```
